# Key Findings: Cornelissen 2024 — Post-COVID Symptom Clusters

## Main Findings
1. **ME/CFS criteria met:** A significant subgroup of post-COVID patients met ME/CFS criteria, clustering separately from other post-COVID phenotypes.
2. **Symptom cluster overlap:** The ME/CFS-like post-COVID cluster showed substantial symptom overlap with reference ME/CFS cohort.
3. **P4O2 consortium:** Large Dutch post-COVID precision medicine cohort.

## Clinical Implications
- Not all post-COVID fatigue is the same — ME/CFS cluster is distinguishable
- Cluster analysis supports ME/CFS as a distinct post-COVID phenotype

## Limitations
- Cluster analysis methodology limits direct incidence estimates
- Questionnaire-based symptom assessment
- Dutch population (generalizability)
