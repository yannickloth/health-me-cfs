## Cascade branches traced

### Branch A — RLS indication (the only validated use)
- Steps: chronic RLS (brain-iron-deficiency + dopaminergic signalling per @Winkelman2025RLSguideline) → (A2) D2/D3 postsynaptic drive in RLS-relevant circuits → (A3) pramipexole full D2/D3 agonism at 0.125–0.5 mg/day → (A4) IRLS relief (days to 2 weeks).
- Interception: **pramipexole** (D2/D3 full agonist, negligible D1) — indication-validated in RLS, untested in ME/CFS-RLS.
- Quantified liability on this branch: augmentation 9.1% in a pramipexole-treated RLS cohort, dose- and duration-dependent, cut-off 0.375 mg/day @Takahashi2017RLSaugmentation; 7.7% at 0.5 mg in the 52-week head-to-head vs 2.1% pregabalin @Allen2014PregabalinPramipexole.
- Discriminating probe: IRLS serial + augmentation screen (dose, duration, spread to upper limbs).

### Branch B — Supersensitivity-worsening (the ME/CFS framework branch)
- Steps: chronic tonic DA deficiency (postulated in ME/CFS) → (B2) D2/D3 upregulation (supersensitivity) → (B3) full agonist drives upregulated receptors to maximal activation without D1-go co-activation → (B4) maladaptive overstimulation: exaggerated low-dose side effects (nausea, dizziness, somnolence) + no core-symptom benefit or worsening.
- Interception: **pramipexole** is the probe of this branch — the side-effect profile at RLS doses IS the assay (@sec:ligand-receptor-duality, Category II).
- Graded probe: **nausea-threshold dose (NTD)** (@sec:nausea-threshold-dose) — NTD below the healthy-volunteer reference (measurable central/CV effects at 0.5 mg, @Samuels2006PramipexoleModafinil) = graded Pattern-1 confirmation; NTD at/above reference = premise fails for that patient; no nausea at any dose = Pattern-5 sentinel.
- Counter-evidence on the premise (B1): normal CSF DA/DOPAC/HVA with selective noradrenergic deficiency in PI-ME/CFS @Aregawi2026Noradrenergic — the deficiency that drives upregulation is not documented in this population. The branch is therefore a hypothesis (0.35 cap), not an established pathway.
- Author case: D2 supersensitivity confirmed by LDA microdose akathisia; pramipexole (Sifrol) gave nausea/dizziness/worsened fatigue, not relief — qualitative Pattern-1, no NTD recorded (the recorded gap the assay closes).

### Branch C — Reward/motivation (positive control in non-supersensitive systems)
- Steps: intact terminals/receptors (no supersensitivity) → (C2) full agonist engages reward circuitry → (C3) anhedonia (SHAPS) improves, light activity increases — PET-verified ventral-striatal target engagement @Ventorp2026PramipexoleAnhedonia.
- Consequence for ME/CFS: the same drug's net direction is receptor-state-dependent (help / null / worsen across the three states: intact, ambiguous, supersensitive) — this is why the analogues conflict (@cf:pramipexole-fatigue-analogue-conflict). The transferable claim is "motivated reward behaviour is drug-modifiable"; "ME/CFS fatigue improves" is not supported (Oved: fatigability unchanged, somnolence up @Oved2006DAAgonistFatigueSomnolence).

### Branch D — Impulse control (mesolimbic overdrive)
- Steps: chronic full-agonist mesolimbic D2/D3 stimulation → (D2) ICD (gambling, buying, hypersexuality, compulsive internet).
- Key fact: **aripiprazole is NOT ICD-sparing** — aripiprazole ICD RR 7.71, gambling RR 5.23; pramipexole gambling RR 7.61 @Etminan2017ICDPharmacoepi. Both agents in any combination scenario carry the black-box warning; QUIP-RS baseline + monthly ×3.
- ME/CFS validity caveat: QUIP-RS domain profile in a bedbound patient may shift toward shopping/internet items (idea 9.3, open).

### Branch E — Augmentation → DAWS (duration-driven)
- Steps: chronic full agonist (dose × duration) → (E2) augmentation (early-onset worsening, spread, shortened window) → (E3) withdrawal attempt → (E4) DAWS (anxiety, paresthesia, insomnia, autonomic distress) — mimics an ME/CFS crash.
- Rescue evidence (cross-disease, severe RLS): aripiprazole 5 mg/day (psychiatric range, above the LDA window) + gradual DA taper → complete DA withdrawal 18/18 @GarciaMalo2026AripiprazoleRLSAugmentation; structured protocol 24/31 (77%) @MartinGarcia2026DAWSRLS. Same PI team/center → one independent source + one corroborating.
- Access asymmetry: the evidence-bearing rescue dose (5 mg) is off-the-shelf; the ME/CFS LDA window's lower end (0.25–1 mg) needs compounding.
- ME/CFS-specific: DAWS-vs-crash discrimination rule (latency after dose cut, anxiety/autonomic predominance, no exertion trigger vs exertion-linked 3–9 d lag) + slower taper + orthostatic vitals per step (@pwarn:pramipexole-mecfs-safety).

### Branch F — Prolactin / dopaminergic tone (peripheral readout, new)
- Steps: low tonic tuberoinfundibular DA (deficiency state) → (F2) disinhibited lactotrophs → (F3) elevated baseline prolactin → D2/D3 agonist corrects tone and suppresses prolactin (serial engagement proxy; human analogue of the Ventorp PET readout).
- Anchor: post-polio bromocriptine responders ~2× prolactin + low fasting ACTH vs non-responders (n = 5) @Bruno1996BromocriptinePostPolio; convergent ME/CFS signal: exaggerated buspirone-prolactin challenge response @cf:prolactin-buspirone-exaggerated.
- Certainty 0.25 (CAP-2-consistent); competing explanations: stress/thyroid/co-prescription prolactin elevation, ACTH = HPA not DA, pre-2010 criteria era.

### Branch G — PK (formulation + clearance)
- ER 0.75 mg qd ≈ IR 0.25 mg TID at steady state (AUCss 17.4 vs 16.0; Cmax 0.967 vs 1.09) — kinetic difference only (flatter peak) @Jenner2009PramipexoleERpk; no tolerability trial compares formulations; higher interindividual CV with ER (30.1% vs 21.4%).
- Renal clearance ~80%, CYP-independent, t½ 12.9 h @Wright1997Pramipexolepk. Caffeine PK interaction REFUTED (no CYP axis); only association is PD pharmacodynamic, CI crosses null @Wills2013CaffeineDyskinesia.
- Real interaction axis: OCT2/MATE renal secretion — cimetidine (in-vitro MATE inhibition), amantadine (shared substrate space) @Knop2015PramipexoleRenal.

## Key discriminating probes
1. **NTD** (@sec:nausea-threshold-dose) — zero-cost, serial, graded D2/D3 competence assay; separates Branch B (below reference) from null (at/above) from Pattern-5 (none).
2. **Serial prolactin** — baseline enrichment + dose-dependent fall = engagement (Branch F); severity-safe (blood draw).
3. **QUIP-RS baseline + monthly ×3** — Branch D; applies to BOTH agents.
4. **DAWS-vs-crash diary rule** — Branch E attribution after any taper.
5. (Research grade) VMAT2 PET + D2 availability PET — density-vs-functional supersensitivity discrimination (brainstorm 2.2); Aregawi 2026 normal CSF DA is the standing premise challenge.

## Pruned branches
- **Caffeine PK interaction** — PRUNED (refuted: renal ~80% clearance, CYP-independent; Wright 1997, Knop 2015). Only the PD A2A pharmacodynamic association retained, CI-crosses-null.
- **"1990s bromocriptine-CFS trials"** — PRUNED as citation targets (unresolvable as primary records; verified 43-query search). Citable anchor: Bruno 1996 post-polio n=5. Citation-hygiene rule: never cite the 1990s CFS claims as primary trials.
- **Nutraceutical D2/D3 analogues (mucuna etc.)** — PRUNED (no pramipexole-equivalent receptor event at controlled dose; mucuna = uncontrolled-dose L-DOPA inheriting all contraindications).
- **Modafinil offset as established interaction management** — PRUNED to open-question (only healthy-volunteer quantification + single PD pharmacovigilance comment; opposing-direction interaction blocks stronger env type per drug-interaction pre-check).
