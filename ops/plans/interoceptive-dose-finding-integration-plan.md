# Integration Plan: Interoceptive Dose-Finding

**Purpose:** Reframe deliberate intermittent dosing ("non-adherence") in ME/CFS as rational interoceptive experimentation — patients testing the hormetic window through body-awareness. Connect existing paper content (hormetic dose-response, paradoxical reactor, interoceptive prediction error, allostatic-interoceptive network) that currently treats non-adherence as a safety measure for fragile patients, not as rational dose-finding.

**Target chapters:** ch27 (medication sensitivity phenotypes), ch15 (integrative models, interoception section), ch33 sec-10 (side effects as diagnostic probes)

**Pre-identified hypotheses:**
- `hyp:interoceptive-dose-finding` (cert ~0.35): Patients who deliberately vary dosing intervals are running an N-of-1 dose-response trial using interoceptive feedback as the endpoint — this is Bayesian inference, not non-adherence.
- `spec:interoceptive-hormetic-window-testing` (cert ~0.25): The allostatic-interoceptive network (insula, ACC, brainstem) computes the hormetic window through repeated perturbation-and-sensing cycles — pulsing is a deliberate perturbation, and the patient's dose adjustment reflects the network's computation.

**Evidence base:** No new literature needed — all mechanistic pieces already in paper (ch15 hormesis paragraph, ch15 interoception, ch18 allostatic network, ch27 paradoxical reactor, ch33 inverted-U diagnostic pattern).
