# Menstrual Cycle as Endogenous Pharmacodiagnostic Probe — Integration Plan

**Purpose:** Integrate the concept that menstrual cycle hormonal fluctuations (oestrogen, progesterone, allopregnanolone) can be used as an endogenous probe to infer which receptor system a drug acts through — by tracking drug response across follicular vs. luteal phases and using differential response patterns to discriminate mechanisms.

**Target chapters:**
- ch30 sec-10 subsec-07 (endogenous probes) — extend existing menstrual cycle section
- ch10 sec-07 (neurosteroid axis) — cross-reference
- ch24 (treatment) — hormonal optimization section cross-ref

**Pre-identified hypotheses:**
- Menstrual cycle drug response variation → hormone-coupled mechanism identification (cert 0.25)
- Oestrogen-dependent drug response (follicular benefit) → NMDA, D2, 5-HT1A mechanism
- Progesterone/GABA-dependent drug response (luteal benefit) → GABA-A mechanism
- Flat response across cycle → hormone-independent mechanism
