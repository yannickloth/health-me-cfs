# TRPV1-Temperature Axis as Autonomic Stress Test — Integration Plan

**Purpose:** Integrate the cross-domain hypothesis that an exogenous thermal challenge (sauna/cold plunge) functions as a controlled autonomic stress test via TRPV1-expressing sensory neurons driving sympathetic outflow. In ME/CFS, post-thermal autonomic recovery time > X minutes predicts PEM threshold. Bridges ch08 (TRPV1), ch10 (autonomic/cardiovascular), ch15 (PEM threshold). Testable at home with thermometer + timer — no lab required.

**Target chapters:**
- ch08 (TRPV1 ion channels — ambroxol-TRPV1 content)
- ch10/ch11 (cardiovascular / autonomic dysfunction)
- ch15 (integrative models — PEM threshold prediction)
- ch18 (symptom-producing mechanisms — PEM)
- ch30 (mechanistic cascade tracing — autonomic + TRPV1 category)

**Pre-identified hypotheses:**
- TRPV1 thermal activation → sympathetic outflow → measurable autonomic response (heart rate, skin temperature, blood pressure)
- Post-thermal autonomic recovery time is prolonged in ME/CFS vs healthy controls
- Recovery time correlates with PEM threshold (longer recovery → lower PEM threshold)
- This constitutes a low-cost, at-home autonomic stress test

**Parent topics:**
- heat-cold-thermoregulation (completed — Phase 13 committed)
- ambroxol-trpv1 (Phase 13 committed as per integration-guide)
