# Diurnal Response Window as Circadian Pharmacodiagnostic Probe — Integration Plan

**Purpose:** Integrate the concept that time-of-day variation in drug response can be used as a pharmacodiagnostic probe — if a drug works at 08:00 but not 20:00 (or vice versa), the diurnal sensitivity reveals circadian-gated receptor expression, hormone coupling, or sleep-dependent mechanisms. This systematises chronopharmacology for ME/CFS mechanism inference.

**Target chapters:**
- ch30 sec-10 subsec-07 (endogenous probes) — new subsection for diurnal/temporal probes
- ch30 sec-10 subsec-08 (onset latency, washout, dose×time) or contribute to existing subsec

**Pre-identified hypotheses:**
- Diurnal drug response variation → circadian-coupled vs. constitutively expressed receptor identification (cert 0.20)
- Morning-only response (08:00 benefit) → cortisol/GR-coupled mechanism
- Evening-only response (20:00 benefit) → melatonin-coupled or sleep-dependent mechanism
- Flat response across time windows → receptor constitutively expressed or mechanism downstream of circadian coupling

**Relation to existing content:**
- ch30 sec-10 subsec-07 already has `subsubsec-01-menstrual-cycle-as-dopaminergic-and-mast-cell-probe.typ` (basic diagnostic) and `subsubsec-05-menstrual-cycle-as-endogenous-pharmacodiagnostic-probe.typ` (pharmacodiagnostic tracking). Diurnal response window is the circadian counterpart to menstrual cycle's monthly timescale.
- Circadian receptor expression literature is well-established in chronopharmacology but not systematised for ME/CFS.
- Overlaps with 11a (response onset latency), 11c (dose×time interaction), and 3a (identical to 11d via different brainstorm sections). These should be integrated as a unified temporal probes subsection.
