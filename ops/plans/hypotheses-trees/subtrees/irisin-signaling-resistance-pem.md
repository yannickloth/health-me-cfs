## Integration Context

**Priority:** 🟡 medium — single cross-sectional cohort; mechanistic framework plausible but hypothesis-stage
**ME/CFS links:**
- Souma 2026: lower baseline irisin + blunted exertional irisin response in ME/CFS (CCC, n=92)
- Baseline irisin independently predicts fatigue severity (β=0.67, p=0.021) — severity paradox
- Moderate-to-severe patients show elevated both irisin AND TSP-1 (Cohen's d 0.51/0.53)
- Functional CDS: TSP-1 antagonizes irisin signaling via HSP90α/αvβ5; TSP-1 dominant antagonist
- TSP-1 suppresses NO/angiogenesis via CD47
- Sex-specific: irisin-PEM correlation male-only (R=0.53)
**Target chapters:** ch07 (energy metabolism), hypothesis-registry, ch30 cascade (potential)
**Pre-identified hypotheses:** irisin signaling resistance via TSP-1; severity paradox = compensation vs distinct biology; TSP-1 as vascular↔metabolic convergence node
**Caveats:** single cohort, Moreau-group biobank overlap, irisin ELISA caveat (Elsen 2014), in vitro mechanism (translation gap), null evidence (FM Ercan, sarcopenia Lapauw)
