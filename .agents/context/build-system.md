# Build System

Typst → PDF + Quarto HTML web generation. Nix-hermetic; Java generator bridge.

## Build Commands

Run from project root. `result/` is a symlink into the Nix store; `cp result/<file> .` to persist outside the store.

| Command | Output |
|---------|--------|
| `nix build` | `result/loth2026-mecfs.pdf` (default) |
| `nix build .#web` | `result/` → Quarto HTML site (no PDF) |
| `nix build .#web-full` | `result/` → HTML site + PDF |
| `nix flake check` | section-audit, qmd-label-audit, typst-source-audit, blog-audit |
| `nix run .#clean` | Remove `.cache`, `.build`, `result`, `target`, `*.pdf` under `src/main/typst/` |
| `nix develop` | Dev shell (typst, quarto, jdk25); TYPST_PACKAGE_CACHE_PATH, TYPST_FONT_PATHS preset |

`nix run .#clean` removes `target/` (all web build output: generated .qmd intermediates + rendered site).

### Build without Nix

The same steps work with a plain toolchain on `PATH`: **Java ≥ 25**, **Quarto**, **Typst** (with `cetz` + `oxifmt` cached), and **Node ≥ 22** for JS tests. Fonts are bundled in-repo. Set the env vars, then run the pipeline manually:

```bash
export TYPST_FONT_PATHS="src/main/typst/mecfs/fonts"
export TYPST_PACKAGE_CACHE_PATH="$HOME/.local/share/typst/packages"

java --source 25 src/build/java/BuildWeb.java
java --source 25 src/build/java/GenerateSidebar.java target/quarto target/quarto/mecfs-sidebar.json
bash src/build/build-isolated.sh
java --source 25 src/build/java/GenerateSiteIndex.java target/site
```

Clean without Nix: `rm -rf target .cache .build`.

## PDF Build

1. `typst compile` on `src/main/typst/mecfs/loth2026-mecfs.typ`
2. Hermetic: pinned typst packages (cetz 0.3.4) + font path
3. Output: `loth2026-mecfs.pdf`

## Web Build (`.#web` / `.#web-full`)

### Generation pipeline

Steps 3–5 are CI audits — they don't gate local rendering but must pass for `nix flake check`.

BuildWeb.java now also copies .bib files — no separate step needed.

| Step | Tool | Detail |
|------|------|--------|
| 1. Assemble + qmd gen | `java --source 25 src/build/java/BuildWeb.java` | Copy `src/main/quarto/` → `target/quarto/`, then Typst → `.qmd` + figures + bib + web assets into `target/quarto/` |
| 2. Sidebar manifest | `java --source 25 src/build/java/GenerateSidebar.java target/quarto target/quarto/mecfs-sidebar.json` | Unified nav manifest for the `<mecfs-sidebar>` component |
| 3. Label audit | `java --source 25 src/test/java/web/QmdLabelAuditTest.java` | Orphaned labels |
| 4. Quality audit | `java --source 25 src/test/java/web/BuildAuditTest.java` | Post-build checks |
| 5. Render | `bash src/build/build-isolated.sh` | Per-unit isolated parallel quarto render → merged `target/site/` |
| 6. Site index | `java --source 25 src/build/java/GenerateSiteIndex.java target/site` | Regenerate search.json / sitemap.xml / robots.txt / listings.json |

### Isolated parallel render (`src/build/build-isolated.sh`)

- Renders each content unit (part1–5, z-appendices, faq, patient-resources, en/de/fr blog, index, about) as its **own isolated quarto project** in `target/units/`.
- Isolation prevents quarto's shared-scratch races (`.quarto/xref`, `site_libs`, mediabag `_files`) that occur when rendering subdirs of one project in parallel.
- Each unit uses `src/main/quarto/_quarto-unit.yml` (`sidebar: false`, full `bibliography:`, include-after-body for the sidebar component).
- Merges all unit `_site` outputs into `target/site/`.

### Sidebar web component

- `src/main/web/mecfs-sidebar.js` + `src/main/web/mecfs-sidebar.html` (hand-written) render the unified sidebar at runtime.
- `target/quarto/mecfs-sidebar.json` (generated by `GenerateSidebar.java`) is the nav manifest.
- Highlights the active page and expands its ancestor sections based on `location.pathname`.

### BuildWeb.java flow

- `src/build/java/BuildWeb.java` orchestrates conversion
- Assemble: wipes `target/quarto/`, copies `src/main/quarto/` (hand-authored content source) in
- Iterates parts 1–5 + appendices + shared
- Per chapter: resolves `#include` directives (recursive, skips figure includes), then runs the Typst→QMD converter in-process
- Figures: compiles each `src/main/typst/mecfs/figures/*.typ` → `target/quarto/figures/*.svg` via `typst compile`
- Copies `src/main/web/` assets (css, JS components, logos, redirects) + `src/main/resources/` (glossary json, part-chapters.json) into `target/quarto/`
- Output dirs: `target/quarto/part*/ch*/`, `target/quarto/z-appendices/`, `target/quarto/_shared/`

### Correct fix discipline

| Symptom | Fix in |
|---------|--------|
| Content/layout issue in rendered HTML | Typst source (`src/main/typst/mecfs/`) or the QMD converter (`src/build/java/`) |
| Static page issue (index, about) | `src/main/quarto/index.qmd` or `src/main/quarto/about.qmd` directly |
| Blog issue | `src/main/quarto/{en,de,fr}/blog/posts/<topic>/<slug>/index.qmd` directly |
| Web component / style | `src/main/web/*.js`, `src/main/web/styles.css` |
| Bibliography issue | `.bib` in `src/main/typst/mecfs/bib/` |
| Figure issue | `.typ` in `src/main/typst/mecfs/figures/` |
| **Never edit** | Generated `.qmd`, `target/`, `target/site/`, `target/quarto/mecfs-sidebar.json` (generated by `GenerateSidebar.java`), `target/site/search.json` (generated by `GenerateSiteIndex.java`) |

### Web components

- `src/main/web/mecfs-sidebar.js` + `src/main/web/mecfs-sidebar.html` — hand-written sidebar web component (injected via `include-after-body`).
- `src/main/web/part-accordion.js` — hand-written home-page chapter-explorer (Bootstrap accordion + carousel), driven by `target/quarto/part-chapters.json`.
- `src/main/web/glossary-tooltip.js`/`.html`, `styles.css` — glossary tooltip + theme, content-independent.
- `target/quarto/mecfs-sidebar.json` — nav manifest, generated by `GenerateSidebar.java`; edit the generator or Typst source, not the JSON.
- Highlighting of the active page and expansion of its ancestor sections is handled at runtime by the component based on `location.pathname`.

### Blog

- NOT generated from Typst
- Handwritten `.qmd` files: `src/main/quarto/{en,de,fr}/blog/posts/<topic>/<slug>/index.qmd` (97 posts per language)
- Posts organized into topic folders; numbered series stay co-located under their topic (see `_blog-plan.md` / `_series-plan.md` in `src/main/quarto/{en,de,fr}/blog/`)
- Series announcing-article for the multi-topic "Conditions That Travel With ME/CFS" sits at `src/main/quarto/{en,de,fr}/blog/posts/co-occurring-conditions-series/`
- Out-of-date paths get a `<meta http-equiv="refresh">` `index.html` redirect, stored in `src/main/web/{en,de,fr}/blog/posts/<slug>/index.html` and copied into `target/quarto/` by `BuildWeb.java` during the build
- Own `_metadata.yml`: sidebar=false, number-sections=false, lang=<de|en|fr>
- Audited by `BlogAuditTest.java` (recursive over `posts/`) across all three language dirs

## Troubleshooting

| Issue | Action |
|-------|--------|
| `nix build` fails | `nix build -L --show-trace` for verbose diagnostics |
| `nix flake check` fails | Check which check name in output; run individually via `nix build .#checks.<system>.<name>` (use `x86_64-linux` on most Linux) |
| `quarto render` fails | Ensure `java --source 25 src/build/java/BuildWeb.java` ran first from project root |
| Web content missing/blank | Run steps 1, 2, 6 from generation pipeline (inside `nix develop`) |
| Figure missing on web | Run `BuildWeb.java` figure compilation; verify `src/main/typst/mecfs/packages/preview/cetz/` exists |
| Typst compile fails outside nix | Enter `nix develop` first (TYPST_PACKAGE_CACHE_PATH + TYPST_FONT_PATHS required) |
| Blog audit fails | `java --source 25 src/test/java/web/BlogAuditTest.java target/quarto/en/blog` (also `target/quarto/de/blog`, `target/quarto/fr/blog`) |
| Stale Nix dependencies | `nix flake update` refreshes `flake.lock`; rebuild after |

## CI/CD (GitHub Actions)

| Workflow | Trigger | Does |
|----------|---------|------|
| `ci.yml` | PR → main | `nix flake check` |
| `build-pdf.yml` | push or PR → main, manual | PDF build + GitHub Release `latest` (no `nix flake check`) |
| `deploy-web.yml` | push → main, manual | `nix build .#web` → GitHub Pages deploy; waits for `build-pdf.yml`, then copies `loth2026-mecfs.pdf` into site root |

## Source Layout

```
src/
├── main/
│   ├── typst/mecfs/           # Typst sources (PDF + web content source)
│   │   ├── loth2026-mecfs.typ # Root doc
│   │   ├── fonts/  packages/  bib/  figures/  shared/  appendices/
│   │   ├── part1-clinical/ … part5-modeling/
│   ├── quarto/                # Hand-authored quarto website source
│   │   ├── index.qmd  about.qmd  _quarto.yml  _quarto-unit.yml
│   │   ├── faq/  patient-resources/  {en,de,fr}/blog/**
│   ├── web/                   # Content-independent web-dev assets
│   │   ├── styles.css  mecfs-sidebar.{js,html}  part-accordion.js
│   │   ├── glossary-tooltip.{js,html}  logos/  {en,de,fr}/blog/posts/*/index.html
│   └── resources/             # glossary-{en,fr,de}.json, part-chapters.json
├── build/
│   ├── java/                  # Build tools: BuildWeb, GenerateSidebar, GenerateSiteIndex, converters
│   └── build-isolated.sh      # Per-unit isolated quarto render
└── test/
    ├── java/web/              # Audit tests (SectionAudit, Qmd*, BuildAudit, BlogAudit, TypstSource)
    ├── js/                    # glossary-tooltip tests
    └── web/preview.html       # theme style preview

target/                        # ALL web build output (gitignored)
├── quarto/                    # Assembled intermediate (.qmd + figures + assets)
├── units/                     # Per-unit isolated render staging
└── site/                      # Final rendered HTML
```

## Nix Flake Structure

| Attribute | Type | Description |
|-----------|------|-------------|
| `packages.default` | pkg | PDF only |
| `packages.web` | pkg | Web only (qmd + quarto) |
| `packages.web-full` | pkg | Web + PDF |
| `apps.clean` | app | Remove build artifacts |
| `checks.section-audit` | check | `SectionAuditTest.java` |
| `checks.qmd-label-audit` | check | BuildWeb + QmdLabelAuditTest + QmdEnvironmentCountTest + QmdQualityAuditTest |
| `checks.typst-source-audit` | check | `TypstSourceAuditTest.java` |
| `checks.blog-audit` | check | `BlogAuditTest.java` |
| `devShells.default` | shell | typst + quarto + jdk25; TYPST_PACKAGE_CACHE_PATH, TYPST_FONT_PATHS preset |

Note: `checks.qmd-label-audit` bundles generation (BuildWeb) + 3 audit tests under one check name.
