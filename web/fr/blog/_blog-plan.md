# Pipeline d'articles de blog : symptômes sans leur déclencheur dans le ME/CFS

| Statut : # Terminé · → Planifié · - Non commencé | Calibration : intro centrée sur le patient, puis science |
|---|---|

Chaque article suit la même structure que [muscle-pain-without-exertion](posts/muscle-pain-without-exertion/index.qmd) :
1. Vignette d'expérience du patient (2e personne, sensorielle, immédiate)
2. « Chez les personnes en bonne santé, X se produit quand Y. Dans le ME/CFS, X se produit sans Y. »
3. Mécanismes candidats (avec niveaux de preuve : confirmé / inférentiel / spéculatif)
4. Prédictions falsifiables
5. Pourquoi l'explication conventionnelle se trompe
6. Ce que vous pouvez faire (avec mises en garde cliniques / avertissement concernant les signaux d'alerte)

## - #1 : comportement de malaise pseudo-grippal sans infection

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Vous vous sentez empoisonné. Courbatures, fièvre, malaise si profond qu'il ressemble au début de la grippe — celle où vous savez que vous allez être anéanti pendant une semaine. Mais la fièvre ne vient jamais. Vous n'êtes pas contagieux. Vous vous sentez juste malade, sans être malade. » |
| **Déclencheur normal** | Infection active → cytokines périphériques → comportement de malaise |
| **Mécanisme ME/CFS** | L'activation microgliale chronique maintient la signalisation hypothalamique de la PGE2 indépendamment de l'activation immunitaire périphérique. « Comportement de malaise verrouillé » — neuroinflammation confinée au SNC qui maintient le programme après l'élimination virale |
| **Lignes doc clés** | ch15-symptom-producing-mechanisms.typ:175, 316–337 ; ch16-causal-hierarchy.typ:394 |
| **Prédiction falsifiable** | Si les inhibiteurs de la COX-2 réduisent les symptômes pseudo-grippaux sans affecter les marqueurs d'infection, la source de la PGE2 dans le SNC est confirmée |
| **Peut être associé à** | #3 brouillard cérébral, #10 cachexie sans cancer |

## - #2 : sommeil non réparateur malgré un nombre d'heures adéquat

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Vous avez dormi neuf heures. Pièce sombre, aucune interruption, coucher tôt. Et vous vous réveillez comme si vous n'aviez pas dormi du tout — lourd, empoisonné, les yeux qui brûlent. Le sommeil a eu lieu. La récupération, non. » |
| **Déclencheur normal** | Privation de sommeil → accumulation de déchets → fatigue au réveil |
| **Mécanisme ME/CFS** | L'hyperactivation constitutive de mTORC1 émousse la poussée d'autophagie nocturne → les protéines/mitochondries endommagées s'accumulent pendant la nuit malgré une architecture de sommeil objectivement normale. L'inflammation confinée au SNC bloque aussi la réduction synaptique (preuves par TEP SV2A) |
| **Lignes doc clés** | hypothesis-registry.typ:1870–1872 ; ch08-neurological.typ:555–580 |
| **Prédiction falsifiable** | Si un inducteur d'autophagie (p. ex. spermidine, mimétique du jeûne) réduit les symptômes matinaux indépendamment de la durée du sommeil, le mécanisme mTORC1/autophagie est confirmé |
| **Peut être associé à** | #3 brouillard cérébral, discussion du sommeil alpha-delta de ch08 |

## - #3 : brouillard cérébral indépendant de l'humeur et de la privation de sommeil

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Vous n'êtes pas déprimé. Vous n'êtes pas privé de sommeil. Vous voulez réfléchir — et les mots se dissolvent avant d'avoir fini de se former. L'écran devient flou. Quelqu'un prononce la troisième phrase pendant que vous décodez encore la première. Vous n'êtes pas paresseux ou distrait. Vous êtes dans le brouillard. » |
| **Déclencheur normal** | Privation de sommeil, trouble de l'humeur ou défi métabolique aigu |
| **Mécanisme ME/CFS** | Neuroinflammation → activation microgliale → fonction synaptique altérée. L'hypoperfusion cérébrale réduit l'apport en oxygène/glucose. Carence centrale en catécholamines (faible dopamine/noradrénaline dans le LCR). Ces trois facteurs fonctionnent indépendamment de l'humeur et de la durée du sommeil |
| **Lignes doc clés** | ch08-neurological.typ:218, 1978 ; ch15-symptom-producing-mechanisms.typ:839 |
| **Prédiction falsifiable** | Si les tests cognitifs montrent une dissociation entre le brouillard subjectif et la performance objective, et que l'IRMf montre une hypoperfusion préfrontale corrélée à la gravité du brouillard, le mécanisme perfusif est soutenu |
| **Peut être associé à** | #1 pseudo-grippal, #2 sommeil non réparateur, #4 PEM cognitive |

## - #4 : PEM cognitive — crash sans effort physique

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Vous n'avez pas bougé. Vous avez juste trop réfléchi — une conversation difficile, un e-mail complexe, une décision que vous ne pouviez pas éviter. Et maintenant vous êtes en crash. Douleurs musculaires, sensation d'empoisonnement, des heures au lit. Votre corps paie pour quelque chose que vous avez fait entièrement dans votre tête. » |
| **Déclencheur normal** | Effort physique dépassant l'enveloppe énergétique |
| **Mécanisme ME/CFS** | La PEM est un phénomène à seuil — elle survient chaque fois que la demande métabolique locale dépasse la réserve locale. Le cortex préfrontal est l'un des tissus les plus exigeants en ATP. Un effort cognitif suffisamment intense produit une rupture focale du R_crit → même cascade PEM, anatomiquement restreinte |
| **Lignes doc clés** | ch14d-cross-disease.typ:2125 ; ch39-energy-metabolism-models.typ:435 |
| **Prédiction falsifiable** | Si un CPET cognitif de 2 jours (effort mental standardisé, retest 24 h plus tard) montre une performance aggravée + des symptômes de PEM le jour 2, la PEM cognitive est mesurable objectivement |
| **Peut être associé à** | #3 brouillard cérébral, l'article sur les douleurs musculaires |

## - #5 : symptômes allergiques spontanés — MCAS sans allergène

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « 16 h, encore. Votre visage rougit, votre nez coule, votre gorge se serre — même heure qu'hier, même chose que mardi dernier. Il n'y a pas de pollen. Vous n'avez rien mangé de nouveau. Pas de changement de lessive. Pas de chat. Vos mastocytes ont juste... décidé que c'était le moment. » |
| **Déclencheur normal** | Allergène → pontage des IgE → FcεRI → dégranulation des mastocytes |
| **Mécanisme ME/CFS** | Les voies d'activation non-IgE dominent : substance P, CRH, IL-33, MRGPRX2. La sensibilisation des mastocytes peut suivre les rythmes circadiens → dégranulation spontanée à des moments prévisibles sans exposition à un déclencheur |
| **Lignes doc clés** | ch14d-cross-disease.typ:1034 ; ch14b-autoimmune-immune.typ:704 |
| **Prédiction falsifiable** | Si les stabilisateurs de mastocytes (cromolyne, kétotifène) réduisent les symptômes indépendamment de l'évitement de l'allergène, l'activation non-IgE est confirmée |
| **Peut être associé à** | #1 pseudo-grippal, #7 poussée immunitaire |

## - #6 : physiologie orthostatique au repos — tachycardie sans station debout

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Vous êtes allongé. Horizontal, immobile, calme. Et votre cœur est à 95. Vous prenez votre pouls parce qu'il semble anormal — une pièce silencieuse, un corps reposé, et votre cœur bat comme si vous veniez de monter un escalier. Vous n'avez pas bougé. » |
| **Déclencheur normal** | Défi orthostatique → baroréflexe → tachycardie compensatrice |
| **Mécanisme ME/CFS** | Dissociation autonomique central-périphérique : le tonus sympathique périphérique est élevé indépendamment du contrôle central. Volume sanguin réduit + dysfonction endothéliale → tachycardie compensatrice même en décubitus |
| **Lignes doc clés** | ch08-neurological.typ:383–385 ; ch14d-cross-disease.typ:901 |
| **Prédiction falsifiable** | Si la noradrénaline plasmatique au repos est élevée et que la fréquence cardiaque se normalise avec un blocage alpha, l'excès sympathique périphérique est confirmé |
| **Peut être associé à** | Le cluster autonomique entier : POTS, volume sanguin, auto-anticorps α-adrénergiques |

## - #7 : poussée immunitaire sans infection active

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Ganglions gonflés, mal de gorge, cette lourde sensation immunitaire — mais pas de virus. Pas de fièvre. Pas de test positif. Votre corps monte une réponse immunitaire contre rien. Ou plus exactement, contre lui-même. » |
| **Déclencheur normal** | Pathogène actif → activation immunitaire innée/adaptative |
| **Mécanisme ME/CFS** | Trois boucles auto-entretenues : (1) propagation d'ARN satellite exosomique HSAT2 → TLR7 → IFN (2) sénescence endothéliale SASP → libération chronique de cytokines (3) sanctuaire de plasmocytes à longue durée de vie → production d'auto-anticorps sans restimulation des lymphocytes B |
| **Lignes doc clés** | ch07-immune-dysfunction.typ:1710, 2924 ; ch43-temporal-evolution.typ:61 |
| **Prédiction falsifiable** | Si les inhibiteurs d'anti-IFNAR ou de JAK réduisent les symptômes immunitaires, la boucle d'interféron est opérante. Si la plasmaphérèse réduit les symptômes, la boucle d'auto-anticorps est opérante |
| **Peut être associé à** | #1 pseudo-grippal, #5 MCAS |

## - #8 : cyclisme endogène rémission-rechute — sans déclencheur identifiable

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Vous passez une bonne semaine. Vous n'avez rien fait de différent — même repos, même régime, même rythme. Et puis jeudi arrive et vous êtes de retour au lit. Il n'y a eu aucun déclencheur. Aucun effort. Aucune infection. Le crash a juste... fait son apparition. » |
| **Déclencheur normal** | Perturbation exogène (stress, infection, sureffort) |
| **Mécanisme ME/CFS** | Rétroaction positive couplée multi-système (énergie-immunité, neuro-immunité) + rétroaction négative retardée (cortisol, cytokines anti-inflammatoires) → bifurcation de Hopf → oscillations de cycle limite. La rémission-rechute est une propriété dynamique endogène du système |
| **Lignes doc clés** | ch42-integrated-systems.typ:222 ; ch43-temporal-evolution.typ:97, 576 |
| **Prédiction falsifiable** | Si les données de séries temporelles (scores quotidiens de symptômes + biomarqueurs) montrent une périodicité correspondant aux prédictions du modèle, même lorsque les déclencheurs externes sont contrôlés, l'oscillation endogène est confirmée |
| **Peut être associé à** | #1 pseudo-grippal (oscillations du comportement de malaise), ch39-energy-metabolism-models |

## - #10 : arrêt métabolique de type cachexie sans cancer

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Votre corps conserve de l'énergie comme si vous mouriez de faim ou d'une maladie — mais ce n'est pas le cas. Vous mangez. Vous vous reposez. Vous ne combattez pas une tumeur. Et pourtant votre métabolisme est passé en mode survie conçu pour une maladie grave, et il ne veut pas revenir en arrière. » |
| **Déclencheur normal** | Cancer, infection grave, traumatisme → arrêt métabolique pour la survie |
| **Mécanisme ME/CFS** | L'état hypométabolique (de type dauer) documenté par Naviaux : programme métabolique « mode sûr » conçu pour la survie lors de conditions menaçant le pronostic vital, verrouillé de manière inappropriée. « Cachexie sans cancer » |
| **Lignes doc clés** | ch14d-cross-disease.typ:1742 ; ch06-energy-metabolism.typ:1749 |
| **Prédiction falsifiable** | Si la métabolomique montre la même signature hypométabolique conservée dans le ME/CFS, le COVID long et la cachexie cancéreuse, l'hypothèse du programme partagé est soutenue |
| **Peut être associé à** | #1 pseudo-grippal (les deux sont des programmes « le corps pense qu'il est en train de mourir ») |

## # symptômes du patient au repos dans une maladie grave — budget énergétique négatif

| Champ | Valeur |
|-------|-------|
| **Accroche patient** | « Vous êtes si sévèrement atteint que vous ne pouvez pas satisfaire même les besoins métaboliques de base au repos. Allongé à plat, dans le silence, et votre corps est toujours en déficit. Vous épuisez l'énergie plus vite que vous ne la générez, sans rien faire. » |
| **Déclencheur normal** | Effort → dépassement de l'enveloppe énergétique |
| **Mécanisme ME/CFS** | Budget énergétique négatif : la demande en ATP dépasse la production, même pour les fonctions métaboliques de base. Le corps réduit le métabolisme basal et reporte la réparation pour atteindre un équilibre précaire |
| **Lignes doc clés** | ch39-energy-metabolism-models.typ:435 ; ch06-energy-metabolism.typ:2415 |
| **Prédiction falsifiable** | Si la calorimétrie indirecte montre un taux métabolique au repos inférieur à celui prédit pour la masse corporelle, et que les symptômes s'aggravent avec toute activité au-delà du basal, le budget négatif est confirmé |
| **Peut être associé à** | #4 PEM cognitive, #9 douleurs musculaires |

## Thèmes transversaux pour l'identité de la série

- **« Votre corps exécute un programme conçu pour X — sans que X se produise »** (cachexie, comportement de malaise, orthostase)
- **« Le seuil a baissé »** (sensibilisation des nocicepteurs, PEM, amorçage des mastocytes)
- **« La boucle s'est refermée — et le déclencheur est parti »** (activation immunitaire, neuroinflammation, COX-2/PGE2)
- **« Le nettoyage n'a jamais été terminé »** (glymphatique, autophagie, stress oxydatif pendant la nuit)
